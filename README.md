O Bebezinho Gym Simulator é um jogo de simulação de academia desenvolvido em JavaScript.

A ideia do projeto é criar um jogo onde o jogador pode criar seu personagem, escolher quais músculos deseja treinar, selecionar exercícios e acompanhar a evolução dos seus atributos musculares.

O jogo também possui um sistema de energia, onde cada exercício consome uma quantidade específica de energia. Quando ela acaba, o jogador precisa descansar para continuar treinando.
